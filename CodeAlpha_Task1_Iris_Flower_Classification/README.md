Iris Flower Classification

## About the Project

This project is about classifying Iris flowers into different species
using Machine Learning.

I used the measurements of the flower's sepals and petals to predict
which species the flower belongs to.

The project was completed as part of my CodeAlpha internship.

## Tools and Libraries

For this project, I used:

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Dataset

The dataset contains information about Iris flowers.

The main features used in the project are:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

The Species column is used as the target for classification.

## What I Did

1. Loaded the Iris dataset.
2. Checked the dataset information.
3. Checked for missing values.
4. Viewed basic statistics.
5. Visualized the data using a pair plot.
6. Converted the species names into numerical values.
7. Selected the input features and target.
8. Split the data into training and testing sets.
9. Trained a Decision Tree Classifier.
10. Made predictions on the test data.
11. Checked the model accuracy.
12. Created a confusion matrix and classification report.

## Machine Learning Model

I used a **Decision Tree Classifier** for this project.

The dataset was divided into training and testing data before training
the model.

## Model Evaluation

The model was evaluated using:

- Accuracy
- Confusion Matrix
- Classification Report
